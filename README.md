# USD/JPYの値動きを題材にした機械学習研究

**過去の為替データから売買の判断を作り、その判断が取引コストを考慮しても役立つかを検証するプロジェクトです。**

予測モデルを作るだけでなく、比較実験、データの品質確認、結果からの改善判断までを記録しています。

[研究の概要](docs/OVERVIEW.md) · [コードの読み方](docs/CODE_GUIDE.md) · [詳しい研究結果](docs/RESEARCH_20260909.md) · [用語の説明](docs/GLOSSARY.md)

## 何を、どのように調べているか

対象は米ドル／円（USD/JPY）です。15分ごとの価格を使い、次の30分間の値動きの方向を予測します。
すべての予測で取引するのではなく、モデルの予測スコアや時間帯に応じて取引を選び、取引量も比較します。

例えば「2018年までのデータで学習 → 2019年で設定を選ぶ → 2020年で評価」という順序で、評価年をずらしながら検証します。
過去のある時点で判断したときに、まだ分からなかった将来の価格を使わないことを重視しています。

```mermaid
flowchart LR
    A[過去の価格を整理] --> B[値動きの傾向を数値化]
    B --> C[上がる・下がるを予測]
    C --> D[取引の条件と量を決定]
    D --> E[30分保有して決済]
    E --> F[費用を引いて結果を評価]
```

## この研究で工夫していること

| 工夫 | 具体的な取り組み |
|---|---|
| 比較する条件を明確にする | モデル、取引時間帯、決済方法、取引量を段階的に比較しています。 |
| 良い結果の理由も調べる | 年ごとの成績や取引数を確認し、一部の取引だけが利益を生んでいないかを調べます。 |
| 改善しなかった実験も残す | 採用を見送った方法と、その判断につながった結果を記録しています。 |
| 説明とコードを対応させる | 設定・特徴量・学習・取引計算を分け、元の研究コードとの一致をテストしています。 |

使用技術：Python、pandasによるデータ処理、scikit-learnによる機械学習、時系列検証、GitHub Actionsによる自動テスト。

## 今回の主な発見

**モデルに渡す情報を増やしても、取引成績が改善するとは限りませんでした。**

最新の比較では、値動きなどを表す30個の数値（特徴量）を使う基本モデルと、変動性・相場状態の情報を加えた50特徴量の候補を比べました。
両方とも同じHGBという学習方式を使っています。追加候補は資産の下落幅がやや小さい一方、平均純損益や利益と損失の比率では基本モデルを上回りませんでした。

| 保存された比較結果（2020–2025年） | 基本モデル・30特徴量 | 追加候補・50特徴量 |
|---|---:|---:|
| 評価した取引数 | 1,565 | 1,322 |
| 1取引あたりの平均純損益 | +0.0357% | +0.0216% |
| 利益合計 ÷ 損失合計の絶対値（PF） | 2.950 | 2.017 |
| 資産の最大下落率（決済時点） | −2.17% | −1.95% |

この表は元Notebookの保存結果です。実際に運用して得た収益ではありません。元データの集約方法と、特に成績が高い2022年・2025年の取引は監査が必要です。
そのため、現時点では特徴量追加の採用を保留し、データと取引の確認を次の課題にしています。
