# FXの機械学習・データ品質・仮想売買の研究

USD/JPYの時系列予測を題材に、データの検査、モデル比較、費用込みバックテスト、リアルタイムの仮想売買を実装しています。過去の成績を将来の利益と取り違えず、同じ条件で検証できることを重視しています。

[採用担当者向け・3分ガイド](docs/REVIEW_GUIDE.md) / [現在の結果](docs/RESULTS.md) / [コードの入口](#コードの入口)

## 作ったもの

- pandasによる特徴量生成と、scikit-learnのモデル・確率校正の比較。
- 時系列の順序、売買費用、データ欠損を考慮した評価とバックテスト。
- Finnhub WebSocketでの観測収集、SQLiteへの判断・取引・状態保存。
- 再起動時の重複処理防止、欠損時の見送り・停止を含むpaper trading。
- 合成データのデモ、unit test、GitHub Actionsによる検査。

**主要技術：** Python / pandas / NumPy / scikit-learn / SQLite / WebSocket / AWS EC2 / systemd / GitHub Actions

## 研究・実装で判断したこと

**良すぎる過去成績から、価格系列を調べ直しました。** 年別データと別系列の混在が見つかり、年別15分足だけで265,905行を再構築しました。以前の高いPFは採用せず、再評価した結果を残しています。

**計算の一致と予測の有用性を別々に確認しています。** 特徴量は全履歴のprefix計算と418点で照合しました。過去300取引のリプレイ一致は計算の検査であり、新しい期間で300回取引した結果ではありません。

**候補を増やしても、採用条件は変えていません。** 他通貨や保有時間の追加実験は履歴として保存し、件数・費用条件を満たさなかった候補は採用していません。

## 現在の到達点

固定候補は41特徴量のHGB＋Isotonic、確信度0.58以上、30分保有です。ドル円単独の30日forward paper testをAWS EC2で運転しています。9月28日の確認時点では進行中で、実注文は出していません。

| 検証 | 確認できる結果 | 読み方 |
|---|---|---|
| 再構築後の2020–2025年バックテスト | 1,391取引、PF 1.733627 | 年別選択手順の保存結果。現在の固定モデルを全期間に適用した結果ではない |
| 2026年途中の保存評価 | 300取引、PF 1.825282 | 探索に使った期間を含む。独立した最終テストではない |
| 30日forward・9月28日確認 | 主口座2決済、確定損益 −210.94円 | 初期100万円・固定1倍。未完了、過去評価とは費用・サイズ条件が異なる |

期間、費用、採否、出典は [RESULTS](docs/RESULTS.md) にまとめています。収益性を実証した段階ではありません。
