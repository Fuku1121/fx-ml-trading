# 入力データ

現在の実験入口はネットワークから取得せず、固定CSVを読み込みます。提供Notebookでは
`yfinance` の `JPY=X`・`period="60d"`・`interval="5m"` を使用していましたが、取得日時と
元データのスナップショットは添付されていません。同じコードを後日実行しても同じ価格期間にはなりません。

## CSV契約

```csv
timestamp,Open,High,Low,Close
2026-01-05T09:00:00+09:00,150.000,150.020,149.990,150.010
2026-01-05T09:05:00+09:00,150.010,150.030,150.000,150.020
```

上記は形式説明用の架空データです。日時は**足の開始時刻**。必ずUTC offsetまたはZを指定します。
時刻はAsia/Tokyoに統一し、時刻特徴にも使用します。OHLCは正の有限値で、重複や逆順は拒否します。
Volumeは不要です。5分グリッドに一致する必要があります。欠けた足の補間は行いません。
6本先までに欠測・週末などの時間差があればその候補を除外します。特徴量のrollingは足数単位であり、
週末前の価格を参照し得る点は現行ベースラインの制約です。

`data/raw/usdjpy_5m.csv` に置いてください。各データセットについて提供者・取得日時・期間・
タイムゾーン・bid/ask/midの種別・利用条件を手元のメタデータに記録してください。
生データはGitに含めていません。配布許諾はこの整理作業では確認していません。
