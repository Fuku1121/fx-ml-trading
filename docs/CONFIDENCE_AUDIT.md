# 最新Confidence実験の監査

対象は `FX (1).ipynb` セル35。元Notebookを直接書き換えず、履歴と保存結果を残したうえで、
`src/fx_research/confidence.py` に修正済みの実行入口を追加しました。

| 論点 | 元実験 | 今回の対応 |
|---|---|---|
| 年境界 | 全期間でshift(-2)後、index.yearだけで分割 | label_endが次区間開始以前の行だけ学習する |
| 評価年末 | 翌年に決済する年末の取引を含み得る | 年内にlabel_endが収まる取引だけ評価する |
| 30分の定義 | 2行先が週末・欠測をまたぐ場合も採用 | 15分ずつ連続する2本だけラベルを作る |
| Accuracyの意味 | net_return>0をAccuracyと表示 | net_win_rateとdirection_accuracyを別に出力 |
| 単一クラス | AUCや確率列参照でエラーになり得る | 学習クラス不足は理由つきスキップ、TestのAUC不能はNaN |
| 入力の曖昧さ | naiveな日時もUTCとして扱える | offsetなし時刻・逆順・重複・不正OHLCを拒否する |
| 非重複 | signal_time+30分で次候補を判定 | entry_time/label_endの実時刻を比較する |
| 保存追跡 | Notebookの出力とローカルCSV | 入力・ソースSHA-256、設定、依存関係、年別状態、取引履歴を保存 |

## 成績への影響

変更により評価対象の行と取引が変わり、モデル・選択閾値・成績も変わり得ます。
元の265,905行のCSVはこの添付に含まれておらず、修正後の実価格再実行は行っていません。
保存されていたPF 1.237896を、修正済み実装の成績とはみなしません。

## 意図的に変更していないこと

30特徴、RFの木数・深さ・葉サイズ・seed、一定コスト、閾値候補と選択スコアはセル35の設計を維持しました。
RSIの平均損失0をNaNとする処理も保持しています。特徴量定義を変更する場合は別実験にします。
一定BID系列による損益から定数コストを引く近似であり、実約定bid/ask系列の再現ではありません。

## 統計的な残課題

セル33・34で同じ時期の結果を見ながら閾値を探索しています。セル35が時系列分割でも、
研究全体の選択バイアスは残ります。単純な取引の独立再標本化によるbootstrapだけでは、
時系列依存や探索の影響を十分に評価できません。次は固定仕様の再評価、期間・売買方向の分解、
ブロック単位の再標本化、未使用期間での確認が必要です。
