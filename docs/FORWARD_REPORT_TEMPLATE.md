## 解釈

1. まず処理が完了したか、欠損や停止で比較が偏っていないかを確認します。
2. 通常費用と悪化費用の結果を並べ、取引数と期間を必ず添えます。
3. 取引勝率と全判断の予測正答率を区別します。確率の妥当性は別の将来ラベル分析で評価します。
4. 取引・ラベルの時系列依存性を考慮します。少数データに精密な信頼区間を付けて優位性が確立したように見せません。
5. 件数が少ない、時期が偏る、停止が多い場合は「判断保留」とします。良い結果でも、複数の相場局面での追試が必要です。

今回の期間は既存モデルと候補の比較用です。終了後に条件を最適化した場合は新しい研究として記録し、この期間を再び未使用の最終評価と呼びません。
