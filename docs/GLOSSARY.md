# 用語の説明

| 用語 | この研究での意味 |
|---|---|
| USD/JPY | 米ドルと日本円の交換比率。 |
| 15分足・OHLC | 15分間の始値・高値・安値・終値をまとめた価格データ。 |
| 特徴量 | モデルへの入力となる数値。直近の値動きや価格の変動の大きさなど。 |
| BASE | 比較基準の候補。最新実験では30特徴量のHGBモデル。 |
| CHAMPION | 元コードで50特徴量候補につけた名前。比較に勝ったという意味ではない。 |
| HGB | HistGradientBoostingClassifier。複数の決定木を順に学習する方式。 |
| RF | Random Forest。複数の決定木の予測を組み合わせる方式。 |
| Validation | モデルや取引の設定を選ぶための期間。 |
| Test・Holdout | 選んだ設定を評価するための期間。繰り返し分析に使った期間は、完全に未使用の評価期間とはいえない。 |
| Walk-Forward | 過去で学習し、その後の期間で評価する手順を、時期を進めながら繰り返すこと。 |
| Nested | 評価年より前の期間の中で、設定選択の手順も行うこと。 |
| OOF | その行を学習に使っていないモデルによる予測。ここでは過去年だけで学習する。 |
| Confidence | 上昇・非上昇のうち大きい側の予測確率。実際の勝率を保証する値ではない。 |
| 確率校正・Calibration | 予測確率と実際の発生頻度のずれを、過去の予測結果を使って補正すること。 |
| 閾値 | 取引するかを分ける基準値。予測スコアが基準未満なら見送る。 |
| Session | 取引対象にする時間帯。コードではUTCで指定する。 |
| Position Sizing・Exposure | 取引量・価格変動の影響を受ける大きさ。増やせば利益だけでなく損失も増え得る。 |
| PF | 利益合計を損失合計の絶対値で割った値。1は両者が同じ。勝率ではない。 |
| DD・ドローダウン | それまでの資産の最高値からの下落率。本研究の表は決済時点の資産から計算する。 |
| AUC | 上昇・非上昇の判別順位の良さ。0.5はランダム相当。AUC 0.53は「的中率53%」ではない。 |
| Brier score | 予測確率と実際の結果のずれを測る指標。小さいほど良い。 |
| バックテスト | 過去データ上でルールを適用する模擬評価。実取引の成績ではない。 |
| ペーパートレード | 実際の資金を使わず、市場データや注文処理の動作を確認する段階。 |
