# 評価方法

現在の評価方法の入口です。実験ごとの原条件は [研究履歴](archive/README.md) に保持し、異なる条件の数値を同一の成績に統合しません。

## 時系列とモデル選択

固定候補は15分足から30分保有の方向を判断します。年別に学習・検証・評価を分け、校正、閾値、セッション、サイズを検証側で選ぶ研究です。ランダムな行分割の精度を根拠にはしていません。41特徴量の選択過程とセル番号は [原記録](archive/RESEARCH_FX3.md)、年別の選択値は [clean_annual_saved.csv](../results/published/clean_annual_saved.csv) に残しています。

ただし、何度も参照した2026年途中の結果を未使用テストとは呼びません。現行モデルの成績と、年ごとにモデル・条件を選んだ過去の成績も区別します。追加候補の採用条件は各研究の `protocol.json` に固定し、不合格を後から合格に読み替えません。

## データ品質とleakage

年別Dukascopy BIDの15分足だけで正規履歴を再構築しました。旧データ混在時の結果は現在の性能根拠から外しています。特徴量は未来側を書き換える検査と原本照合を行い、過去の特徴量が将来の値に依存しないかを検査します。

履歴末尾だけを切る計算では一部の特徴量に差が生じたため、全履歴のprefixと418点を照合しました。150本の準備条件は、単に毎回末尾150本だけで同じ値を再現できるという意味ではありません。[固定仕様の記録](archive/FROZEN_SYSTEM.md) に計算条件を保存しています。

## 損益と予測を分ける

AUC・Brier・校正誤差は予測の評価、取引数・PF・費用控除後収益・最大DDは売買規則の評価です。「確信度0.58」は将来の正解率58%の保証ではありません。ラベルが重なる短期間の判断を独立標本として扱いません。

過去の保存バックテストには往復費用0.00004とサイズ選択が含まれます。現行forward主口座は固定1倍で、通常・ストレスのスプレッドとスリッページを別々に引きます。正確な条件と対応する結果は [RESULTS](RESULTS.md) に集約しています。

## forwardの判断と約定

確定足から判断し、判断後に受信した新しい観測で仮想約定します。市場観測価格は実際のbid/ask約定ではありません。品質条件を満たさない足、遅すぎる推論、既存ポジション、終了直前、ロールオーバーを考慮して注文を見送ります。

保有中の長い観測抜けは損益を推測して埋めず停止します。注文待ちの期限、再起動時の重複防止、SQLiteの原子性も検査します。公開参照実装の具体値は [protocol.json](../paper_trading/protocol.json)、運転版との差は [ARCHITECTURE](ARCHITECTURE.md) を参照してください。
