# 研究の概要

米ドル／円の価格を題材に、機械学習の判断を比較し、検証可能な形で実行する方法を研究しています。
価格が上がるかを当てるだけでなく、費用を引いた損益、悪い時期の下落幅、計算の再現性を確認します。

## 今回進んだこと

異常に高い利益の原因を調べ、価格系列が混在したデータを年別の元ファイルから再構築しました。
再検証の結果、相場状態の情報を加えた41特徴量のモデルを採用候補として固定しています。
さらに、過去の判断を仮想売買の処理へ渡し、時刻・価格・取引量・費用の計算が一致するかを確認しました。
最後に実際の市場データを取得し、新しい15分足を待つ状態まで進んでいます。

## 実装で工夫した点

| 観点 | 取り組み |
|---|---|
| データの信頼性 | 不自然な利益をそのまま採用せず、価格の出所まで遡って確認 |
| 再現性 | 研究時と逐次処理で特徴量・取引結果が一致するかを検査 |
| 計算仕様 | いつの価格で入り、いつ出るか、費用をどう引くかを明文化 |
| 状態の管理 | 保有・未処理データ・実行記録を保存し、二重処理を防ぐコードを構築 |
| 結果の説明 | 成功・失敗・未確認の状態を分け、元の保存出力へ辿れる構成 |

## 現在の成果と限界

保存記録では過去300取引の再現が一致しています。ただし、これは将来の新しい市場で300回取引した実績ではありません。
最新API接続の記録は待機状態・処理件数0です。次は新しい確定足を受信して一連の処理を通し、継続実行や障害時の動作を確認します。
モデルの将来の有効性は、仕様を固定した後の未使用データで評価する必要があります。
