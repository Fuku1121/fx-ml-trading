# 採用担当者・技術者向けの読み方

## 3分で把握する

このプロジェクトのテーマは、機械学習の価格予測を、新しい価格を受信し続ける仮想売買へつなげて検証することです。成果はモデルの損益だけでなく、データの誤りを調べ、比較条件を固定し、停止や再起動を含めて判断を保存する仕組みにあります。

収益性の実証は未完了です。多数の候補を探索しましたが、採用基準を満たさない候補を採用済みとは扱っていません。30日間のクラウド比較は履歴準備から開始しており、まだ完成した成績はありません。

## 10分で動きを確認する

[専用環境のセットアップ](../paper_trading/README.md)後、リポジトリのルートで実行します。

```bash
python paper_trading/demo.py
```

人工価格と固定したダミー判断を使い、3口座それぞれの仮想約定・再起動・決済を示します。各口座の決済件数は1、重複注文は0になります。API接続や学習済みモデルを使わず、一時フォルダの状態は終了時に削除します。表示される損益はソフトウェアの説明用で、研究成績ではありません。

## 設計上の判断

- 履歴が欠けた場所を架空の価格で埋めない。特徴量や損益を実際より良く見せないためです。
- 2モデルの主比較では取引量と費用をそろえる。取引量の違いを予測性能の違いと誤認しないためです。
- モデルと期間を固定し、運転途中の結果を見て条件を変更しない。後付けの有利な選択を減らすためです。
- 分からない決済価格を作らず停止する。継続運転の件数より記録の解釈可能性を優先しています。
- 学習済みモデルと生データを配布していないため、完全再現と構成要素のテストを明確に分けます。
