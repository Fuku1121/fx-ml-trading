## 重要な結果

最初の24時間収集は63,624観測、96本の足でした。内訳は完全40本、週末の空足50本、市場時間の空足1本、不完全5本です。週末の休場を通信障害と区別しました。その後、短い観測抜けを明示し、品質条件付きで履歴を利用する方式に変更しました。

9月16日の予測監査は55判断中27正解（49.1%）で、方向予測の強い優位性は確認できません。30分先の判断が重なるため55件を独立した試行とは扱えません。モデルの確信度、方向予測の正答率、費用控除後の取引勝率は別の指標です。

保有時間を変えた検証では一部の条件が改善しましたが、後続の複数通貨検証とはデータ・費用・品質条件が違います。異なる報告の収益率を単純に順位付けしないでください。経済指標について試したのは発表時刻の特徴量であり、ニュース本文や予想との差の取り込みではありません。

72候補の探索では、両評価期間で最低30取引かつ通常・悪化費用とも利益が残る条件を満たした候補は0でした。研究対象のUSD/JPY・120分・他通貨特徴量あり・費用フィルターありは、2025年8取引で約+0.30%、2026年1〜8月34取引で約+1.56%。少なすぎる取引件数が採用見送りの理由です。

同候補の9月1〜15日の追加確認は6取引で約+0.068%。研究で近接する時期を既に参照しており、完全に未閲覧の最終テストとは呼びません。探索した条件数も含めて判断する必要があります。

## 再現できる範囲

各フォルダのREPORT_JA.mdは当日の記録です。CSV・JSONは集計値と条件の閲覧用で、収益率は各報告に記載した期間全体の値です。正規化済みの小数と百分率を混同しないでください。

複数通貨と72候補探索には実験コードも収録しています。`multicurrency-20260917` の取得・学習結果を `edge-search-20260917` が参照する構成です。生データ・モデル・旧運転DBは配布していないため、全実験の再実行には元の入力と各報告の環境が必要です。取得スクリプトは外部通信し、学習・報告スクリプトは出力を書き込みます。閲覧のために実行する必要はありません。

収集監査・予測監査・37条件比較は報告と選択した集計を掲載し、旧Notebook環境に依存する実行スクリプトは同梱していません。研究履歴を保存しつつ、新しい運転の読みやすい入口を [paper_trading](../paper_trading/README.md) に集約しています。
